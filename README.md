🌼 Different-Flowers (Context Study for AR)
📍 Field Visit

Botanical Garden / University Campus

🎯 Objective

To collect real-world images of different flowers and plants for a context study related to an Augmented Reality (AR) project.

📸 Description

This repository contains photographs of various flowers captured during a field visit.
These images will be used for:

Studying plant shapes, colors, and structures

Understanding real-world environments for AR integration

Possible use as reference or dataset for AR object recognition

🛠 Tools Used

Mobile Camera

GitHub for storage and documentation

📁 Contents

Flower images (.jpg format)

README documentation

🧠 Future Use

These images may be used in:

AR flower identification app

3D flower modeling reference

Texture and asset creation for Unity AR projects
